# Pure Mathematics Portfolio

This repository documents my independent self-study in pure mathematics. It serves as an open workspace where I work through core textbooks, solve problem sets by hand, typeset clean proofs in LaTeX, and test my understanding using open problem sets and past exams.

---

## 📚 Books & Subjects Covered

* **General Topology:** *Topology* (2nd Ed.) - James R. Munkres (`proofs/1-munkres-topology-reading/`)
* **Number Theory & Classical Algebra:** *Higher Algebra* - S. Barnard & J. M. Child (`proofs/2-barnard-child-number-theory-reading/`)
* **Complex Analysis:** *Complex Analysis* (3rd Ed.) - Lars V. Ahlfors (`proofs/ahlfors_complex_analysis/`)
* **Abstract Algebra:** *Abstract Algebra* (3rd Ed.) - David S. Dummit & Richard M. Foote (`proofs/dummit-foote-algebra/`)
* **Real Analysis:** *Principles of Mathematical Analysis* (3rd Ed.) - Walter Rudin (`proofs/rudin-real-analysis/`)
